{% comment %} One SVG sprite, inlined once per page and referenced with . Inlined rather than fetched: the set is a few KB, it is needed by the header on the very first paint, and a sprite file would be one more request that can arrive after the icons are already meant to be visible. Every glyph is a 24×24 stroke path so they all sit at the same visual weight. Arrows point LEFT, which is "forward" in Persian. Anything that means "forward" carries class="fwd" and the stylesheet mirrors it for LTR. {% endcomment %}
